# CircuitAtlas

一款独立开发、基于浏览器运行的电工接线与开关逻辑仿真软件。
本原型参考了提供的 ESim 截图中的操作流程，未使用 ESim 的代码、品牌、
图片、授权机制或工程文件格式。

## 启动项目

```sh
npm install
npm run dev
```

Vite 会在终端输出可访问的本机地址，通常为 `http://127.0.0.1:5173/`。

运行测试和构建：

```sh
npm test
npm run build
```

### Windows 后台自启动

在项目目录中打开 PowerShell，执行以下命令安装自启动并查看状态：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\web-server.ps1 -Action Install
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\web-server.ps1 -Action Status
```

`Install` 会立即启动本地网页服务，并注册名为 `EasySIM-Web-5173` 的当前用户
Windows 登录启动项。不需要管理员权限，也不会安装 Windows 系统服务。
服务使用已安装的 Node.js，在后台运行，访问地址为 `http://127.0.0.1:5173/`；
Vite 意外退出后会自动重启。请保留项目和 Node.js 的安装位置，移动后需要重新执行
`Install`。日志保存在 `.cache/web-server/`。

使用 `-Action Start` 可手动启动服务，不改变自启动设置。
使用 `-Action Uninstall` 可取消自启动，但不会停止当前正在运行的网页服务。
服务仅监听本机地址，不会将项目开放给局域网或互联网。
后台运行的仍是现有 Vite 开发服务器，因此修改源码后，页面仍会自动更新。

## 当前功能

- 提供 120 种元件，分为电源类、通用类、交流控件和直流控件四组。
  搜索支持整个元件库，模型筛选可区分逻辑仿真模型与仅接线模型。
- 支持各通道独立操作的多联墙壁开关、选择开关、急停按钮、带灯按钮、
  多极断路器、熔断器、接线端子排和带开关插座。
- 支持交流与直流接触器、8 脚与 14 脚转换继电器、联动辅助触点、
  通电延时继电器、指示灯、塔灯、蜂鸣器、阀、电动机和加热器。
- 接触器提供独立型号：交流线圈 24V、36V、110V、220V、380V，
  直流线圈 24V、48V、110V、220V。220V 和 380V 交流型号另有
  单常开（1NO）或单常闭（1NC）辅助触点版本；三组主触点均为常开。
  这些是本软件的通用教学模型，不对应特定厂家的完整产品型号。
- 实物视图和原理图操作台均支持按住接触器进行瞬时手动吸合。
  主触点及关联辅助触点跟随机械吸合状态，不依赖线圈是否得电。
  松开后，未得电的接触器会释放；正确接线的自锁回路则可维持吸合。
  此功能仅用于软件仿真。
- 支持手动触发传感器、带供电条件的 PNP/NPN 输出、关联测试物料、
  光幕遮挡状态、温控阈值和理想电压读数。
- 支持元件拖放、网格吸附、旋转、复制、删除，以及画布平移和缩放。
- 支持端子之间的正交接线，可自动分配线色，也可手动选择颜色。
- 使用 Graphology 分析连通分量，通过固定点迭代求解触点与线圈状态。
- 提供 16 个已接线示例及 1 个空白接线实操：自锁、点动、两地启停、三地启停、正反转互锁、
  手动热继电器跳闸、双电机顺序启动、延时亮灯、继电器定时顺序控制、
  急停与状态指示、PNP/NPN 传感器、浮球补水、温控加热、
  简单照明和楼梯双控照明。
- 支持相序与星形/三角形接线检查、电源短路检测，以及基础缺相和接地提示。
- 支持撤销、重做、浏览器本地自动保存，以及带校验的 JSON 工程导入与导出。
- 支持确认后只清空接线，或清空全部元件和导线。
  清理保留工程名称，可一步撤销恢复；仿真运行期间禁止清理。

初始工作区包含与所提供示例对应的未接线元件。
从顶部菜单加载示例，开始仿真，合上 QF1，再按住 SB2。
在自锁示例中，松开 SB2 后，KM1 仍保持得电，直到按下 SB1 或断开 QF1。
仿真运行期间禁止修改接线。

延时参数、传感器关联和辅助触点关联可在属性面板中配置。
通电延时示例在 SB1 保持接通后启动；PNP 示例跟随 OBJ1 的状态。
温度输入和调节值可在仿真期间修改。

运行监视和线圈符号会显示实际输入电压与额定线圈电压。
系统会区分回路未接通、欠压、过压和电源类型不匹配等情况。
按下启动按钮时若出现电压不匹配，会给出提示，不会擅自修改元件额定值或接线。

### 三相电机多地控制接线实操

在“示例电路”中选择“三相电机多地控制 · 接线实操”，加载未接线元件。
同名的“参考接线”示例提供完整接线和实时原理图，两者的元件与位置相同。
加载其他示例会替换当前工作区，切换前可导出工程保留练习进度。

第一地按钮为 SB1（停止）和 SB2（启动），第二地为 SB3（停止）和 SB4（启动），
第三地为 SB5（停止）和 SB6（启动）。主电路使用三相电源、QF1、KM1 和 M1，
控制线圈为 AC 220V，HL1 用于显示运行状态。

三处常闭停止触点串联，三处常开启动触点并联。
KM1 的 13/14 常开辅助触点跨接在启动按钮两端形成自锁，
所有启动和自锁支路均位于三处停止触点之后。
接好线路后开始仿真、合上 QF1，可在任意一地启动、在任意一地停止。
停止优先于启动；释放停止按钮或断电后重新合闸，不会自行恢复自锁。
220V 线圈的供电回路采用相线与 N，不应按 380V 线圈接到两根相线之间。
此处仅描述软件中的教学接线，不作为实物施工或带电操作依据。

## 独立元器件百科

访问 `http://127.0.0.1:5173/knowledge.html` 打开独立知识库。
它使用单独的页面入口和样式，不加载接线操作台，也不读取或写入接线工程。
操作台仍保持原地址与原界面；知识库中的“接线操作台”链接在新标签页打开。

知识库覆盖现有全部元件模型，可按名称、规格、端子或知识点搜索，
并按元件分类和电源类型筛选。每个型号包含：

- 作用、工作原理与典型用途。
- 当前型号参数、常见规格解释、选型要点与同类模型对照。
- 实际模型端子表和触点动作条件。
- 常见误区、分析思路，以及真实设备与软件简化模型的边界。

支持以片段地址直接打开型号，例如 `knowledge.html#contactor380`。
知识内容为入门教学资料，并非穷尽所有型号与应用。
具体产品须以制造商铭牌、说明书及适用安全要求为准，不能据此直接进行实物施工。

### 百科分类

百科不再以操作台是否支持仿真作为收录条件，分为两个独立领域：

- 基础电工：保留现有 120 个教学型号及其知识，包括电源、保护、开关、
  接触器、继电器、传感器、仪表、电机、执行器与控制器等。
- 板级电子：首批 12 篇基础词条，包含电阻、电容、电感、二极管、BJT、
  MOSFET、光耦、LDO、Buck、运放、逻辑门及 MCU。每篇包含原理、
  规格选型、封装识别、引脚功能、常见误区、相关词条和官方参考资料。

板级词条只属于百科，不会自动变成接线台元件或新增模拟电路求解功能。
例如 `knowledge.html#pcb-mosfet`、`knowledge.html#pcb-mcu` 可以直接打开词条；
旧的 `#breaker` 等地址保持有效。目录支持跨领域搜索、领域与分类筛选。
百科共 132 个条目，并不等于 132 种完全不同的器件，其中包含现有型号变体。

每个基础电工条目均提供厂商资料位置，区分具体型号、系列参考、分类目录、
未收录资料。目录入口不等于已经导入完整型号数据；没有核实资料时显示
未收录状态，不会使用变频器资料或任意品牌图片填充。
资料当前仍为分批收录，尚未完成所有器件的多厂商实物、型号与 3D 覆盖。

### 厂商实物与三维示意

变频器页面 `knowledge.html#vfd` 默认展示厂商实物资料，首批包含西门子
SINAMICS V20、ABB ACS355、台达 MS300、英威腾 GD20 和汇川 MD200。
可切换厂商和系列、查看官方图库、放大图片并打开对应官方产品资料；
目录搜索支持厂商名称和系列名称。

这些是系列级参考，不是具体订货型号的参数库。系列合照、机座外形及选件

如需对外部署或分发，应先核实并取得相应素材授权，或替换为获授权素材。
厂商资料索引位于 `src/manufacturerCatalog.ts`，与操作台仿真元件独立。

其他资料包括 Finder 继电器、定时、SSR、温控、浪涌和仪表等官方目录，
以及明纬 HDR-60 官方系列与 CAD 下载入口。CAD 链接不表示已转换或可网页预览。

板级内容位于 `src/boardKnowledge.ts`，领域目录与检索位于 `src/encyclopedia.ts`。
添加板级词条无需修改仿真 `Kind`、端子定义或工程文件格式。
板级引脚表只解释功能，不根据封装或系列名推断具体脚号。
外部资料可能受网络、地区和厂商访问策略影响；产品图及文档不授予商业使用许可。

## 实时原理图

工作区标签可切换实物接线、原理图和左右联动视图；窄屏下联动视图改为上下排列。
两种视图共用同一套仿真状态。原理图根据实际导线连接关系重新生成，
不是预先准备的示例图片。

默认的一体化图纸中，每个触点和负载只绘制一次，通过实心连接点连接共用的静态网络，
并由 ELK 提供正交自动布局。共用的启动/自锁触点、并联的线圈与指示灯负载、
电动机绕组跨接线会保持连接在同一张图纸上。
也可切换到分支视图，分别追踪供电和返回路径。
原理图默认以便于阅读的 100% 比例打开，支持滚动、适应整张图纸、适应宽度和缩放。
对未接通或电压不匹配的负载会进行标记，不会虚构供电路径。

操作台提供瞬时按钮、保持型开关、独立墙壁开关通道、选择开关、
手动跳闸与复位、关联测试物料和温度输入。
红色导线表示相线或正极电位，蓝色表示中性线或 0V，
绿色移动标记表示通向已供电负载的闭合路径。
这些标记不代表实测电流、电流大小或交流电方向。
触点图形与仿真求解器使用相同的触点状态判断函数。
点击下载图标可将当前完整原理图导出为独立 SVG 文件。

对于大型或连接关系复杂的工程，路径枚举存在数量上限。
达到上限时，原理图会显示截断提示；实物接线仍保留完整的连接记录。
未使用的触点仍可在实时触点状态列表中查看。
仅接线模型不会因为打开原理图而获得额外的仿真功能。

编辑快捷键：`V` 选择、`W` 接线、`H` 平移、`Escape` 取消、`Delete` 删除、
`Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+D` 复制、`Ctrl+S` 保存、`Ctrl+O` 打开。
鼠标滚轮用于平移，`Ctrl+滚轮` 用于缩放。点击端子可进行接线。

## 重要限制

本项目是开关逻辑教学原型，不是电气设计或安全验证工具。
它不求解模拟电路方程，也不计算真实电流、功率、热过载、触点抖动、
接地故障电流、电机转速或机械负载。
电机旋转仅为根据相序和绕组连接关系推导出的示意状态。
理想电源被视为相互隔离的参考源；为保守起见，系统会拒绝连接不同电源的端子。

当前工程文件格式为 `*.easysim.json`，不是 ESim 的专有格式。
PLC/控制器、变频器、软启动器、安全继电器、变压器、电位器、
电流表、电能表和浪涌保护器均明确归为仅接线模型。
其中部分模型保留了说明中列出的直通路径，
但不会计算内部控制、模拟电路行为或二次侧供电。

断路器和热继电器采用手动分合闸或手动触发跳闸，不模拟自动保护曲线。
蜂鸣器仅显示得电状态，不播放声音。
端子编号是本软件定义的通用映射，不是制造商提供的接线说明。
带有安全名称的设备不提供经过认证的安全逻辑、诊断或验证能力。
通过静态检查不代表电路安全或符合规范。
请勿将本原型作为真实带电作业的依据。
